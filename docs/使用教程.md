## 环境准备

### 安装依赖

首先，确保您已经安装了所有必要的依赖：

```bash
pip install -r requirements.txt
```

### 目录结构准备

确保您的项目目录结构如下：

```
mv-subtitle-tools/
├── models/                          # 模型目录
├── training_data/                   # 训练数据目录
│   ├── mixed_color/                 # 混色字符图片
│   └── normal_color/                # 普通字符图片
├── test_data/                       # 测试数据目录
│   ├── mixed_color/                 # 测试用混色字符图片
│   └── normal_color/                # 测试用普通字符图片
├── processing_output/               # 处理输入目录
│   └── video_id/                    # 视频ID目录，包含帧图片
├── processing_results/              # 处理结果目录
└── mixed_color_results/             # 混色字符结果目录
```

您可以使用以下命令创建这些目录：

```bash
mkdir -p models
mkdir -p training_data/mixed_color training_data/normal_color
mkdir -p test_data/mixed_color test_data/normal_color
mkdir -p processing_output processing_results mixed_color_results
```

## 数据准备

### 训练数据

为了训练混色字符分类器，您需要准备两类图片：

1. **混色字符图片**：包含蓝白渐变等混色效果的字符图片
2. **普通字符图片**：普通单色字符图片

将这些图片分别放入以下目录：

- 混色字符图片：`training_data/mixed_color/`
- 普通字符图片：`training_data/normal_color/`

每个图片应该只包含一个字符，并且尺寸应该相对一致。建议的图片尺寸为32x32或64x64像素。

### 测试数据

同样，您可以准备一些测试数据来评估模型性能：

- 混色字符测试图片：`test_data/mixed_color/`
- 普通字符测试图片：`test_data/normal_color/`

### 视频帧图片

要处理视频中的混色字符，您需要先将视频转换为帧图片。您可以使用FFmpeg等工具提取视频帧：

```bash
ffmpeg -i your_video.mp4 -vf fps=10 processing_output/video_id/frame_%04d.png
```

这将以每秒10帧的速率提取视频帧，并将它们保存到`processing_output/video_id/`目录中。

## 训练混色字符分类器

一旦您准备好了训练数据，就可以训练混色字符分类器：

```bash
python train_mixed_color_classifier.py
```

这个脚本将：

1. 加载训练数据
2. 从每个图片中提取特征
3. 训练一个随机森林分类器
4. 评估模型性能
5. 将模型保存到`models/mixed_color_classifier.joblib`

您可以通过修改脚本中的参数来调整模型性能：

```python
# 调整随机森林参数
model = RandomForestClassifier(
    n_estimators=100,  # 树的数量
    max_depth=None,    # 树的最大深度
    min_samples_split=2,  # 分裂内部节点所需的最小样本数
    random_state=42
)
```

## 处理视频帧

训练好模型后，您可以处理视频帧图片来检测混色字符：

### 处理单个视频

```bash
python process_mixed_color_batch.py --video_id video_id
```

### 处理所有视频

```bash
python process_mixed_color_batch.py --all
```

处理结果将保存在`processing_results/`目录中：

- `all_results.json`：完整的处理结果，包含每个检测到的字符的详细信息
- `mixed_characters.txt`：提取的混色字符列表，每行一个字符

### 处理参数

您可以通过命令行参数调整处理行为：

```bash
python process_mixed_color_batch.py --video_id video_id --model models/your_model.joblib --confidence 0.8
```

参数说明：

- `--video_id`：要处理的视频ID
- `--all`：处理所有视频
- `--model`：模型文件路径
- `--confidence`：分类置信度阈值，默认为0.7
- `--output_dir`：输出目录，默认为`processing_results`

## 结果去重

视频帧中可能包含大量重复的字符，特别是当帧率较高时。您可以使用去重脚本来减少重复：

```bash
python dedup_same_second.py
```

这个脚本将：

1. 加载`processing_results/all_results.json`
2. 对同一秒内的重复字符进行去重
3. 将去重后的结果保存为`processing_results/all_results_deduped.json`
4. 将去重后的字符列表保存为`processing_results/mixed_characters_deduped.txt`

### 去重参数

您可以通过命令行参数调整去重行为：

```bash
python dedup_same_second.py --input processing_results/all_results.json --output processing_results/custom_deduped.json --window 0.5
```

参数说明：

- `--input`：输入结果文件路径
- `--output`：输出结果文件路径
- `--text_output`：文本输出文件路径
- `--window`：时间窗口大小（秒），默认为1.0

## 结果分析

### 可视化混色字符

您可以使用示例脚本来可视化检测到的混色字符：

```bash
python examples/detect_mixed_color_example.py --image your_image.png
```

这将显示检测到的混色字符，并在每个字符周围绘制边界框。

### 统计分析

您可以分析去重前后的字符数量：

```python
import json

# 加载原始结果
with open('processing_results/all_results.json', 'r', encoding='utf-8') as f:
    original_results = json.load(f)

# 加载去重后的结果
with open('processing_results/all_results_deduped.json', 'r', encoding='utf-8') as f:
    deduped_results = json.load(f)

# 计算字符数量
original_count = sum(len(v['mixed_characters']) for v in original_results.values())
deduped_count = sum(len(v['mixed_characters']) for v in deduped_results.values())

# 打印统计信息
print(f"原始: {original_count} 个字符")
print(f"去重后: {deduped_count} 个字符")
print(f"减少了: {original_count - deduped_count} 个字符")
```

## 常见问题

### 1. OCR识别不准确

如果OCR识别不准确，可以尝试以下方法：

- 提高图片质量和分辨率
- 调整PaddleOCR参数，如使用不同的语言模型
- 对图片进行预处理，如增强对比度、去噪等

### 2. 混色字符分类不准确

如果混色字符分类不准确，可以尝试以下方法：

- 增加训练数据量
- 调整特征提取方法
- 尝试不同的分类器或参数
- 增加模型复杂度

### 3. 处理速度慢

如果处理速度慢，可以尝试以下方法：

- 使用GPU加速OCR（需要安装GPU版本的PaddlePaddle）
- 减少处理的帧数，如每秒只处理5帧而不是10帧
- 并行处理多个视频或帧
- 优化特征提取算法

### 4. 内存不足

如果遇到内存不足的问题，可以尝试以下方法：

- 分批处理图片
- 减小图片尺寸
- 优化数据结构
- 增加系统内存或使用虚拟内存
